ملخص العرض

طلبكم يتضمن مشروعين منفصلين تقنياً ومالياً، ونقدّمهما هنا بتسعير مستقل لكل منهما حتى تتمكنوا من اعتماد أحدهما أو كليهما. المشروع الأول موقع تعريفي بثلاث لغات مع لوحة تحكم تُمكّن فريقكم من نشر الأخبار والفعاليات والصور بدون العودة إلينا. المشروع الثاني متجر إلكتروني مستقل يُبنى على تقنيات مفتوحة المصدر، فتبقى ملكيته وكوده وقاعدة بياناته للمدرسة بالكامل.

ربط Odoo مُسعّر بشكل منفصل كما طلبتم، ويمكن تنفيذه لاحقاً دون إعادة بناء المتجر، لأن البنية التي نقترحها تفصل طبقة البيانات عن الواجهة وتتيح المزامنة عبر API.

02

قراءة الطلب — ملاحظات فنية قبل التسعير

قبل عرض الأرقام، هذه أربع نقاط أثّرت مباشرة في اختيارنا التقني وفي بنود العرض، ونرى من الأمانة توضيحها لكم مسبقاً:

شرط تملّك الكود يستبعد منصات الاشتراك

منصات مثل سلة وزد وشوبيفاي تُقدَّم كاشتراك شهري أو سنوي، ولا يُسلَّم معها كود مصدري ولا وصول كامل لقاعدة البيانات. لذلك لا تحقق شرطكم الصريح بتملّك المصدر وعدم الارتباط باشتراك، وقد استُبعدت من هذا العرض. البديل الذي نقترحه مبني على مكوّنات مفتوحة المصدر بتراخيص MIT وGPL، تُثبَّت على خادم باسم المدرسة، ولا تُرتّب أي رسوم ترخيص دورية.

نطاق ‎.sa‎ يتطلب مستندات نظامية

تسجيل النطاق تحت ‎.sa‎ أو ‎.edu.sa‎ يمر عبر مركز المعلومات الوطني (SaudiNIC) ويشترط تطابق اسم النطاق مع السجل التجاري أو الترخيص أو العلامة التجارية. نتولّى الإجراء نيابةً عنكم، لكن التسجيل يتم باسم المدرسة كمالك وإداري، والرسوم تُسدَّد بالتكلفة. وننصح بحجز ‎.com‎ بجانبه كإجراء احترازي.

الفوترة الإلكترونية (ZATCA) قرار يسبق البرمجة

المتجر سيصدر فواتير بيع باسم المدرسة تخضع لنظام الفوترة الإلكترونية. يجب تحديد الجهة المُصدِرة للفاتورة: المتجر نفسه أم Odoo. إن كان المتجر، فإن التكامل مع منصة «فاتورة» (المرحلة الثانية) خدمة منفصلة سعرها 6,000 ر.س. وإن كان Odoo هو المُصدِر فالتكلفة مشمولة ضمن بند الربط.

صفحات «الفروع» و«البطولات» تعني محتوى متغيّراً لا صفحات ثابتة

الأنشطة الرياضية والبطولات والإنجازات ليست صفحات تُكتب مرة واحدة، بل قوائم تنمو كل موسم. لذلك بنيناها في لوحة التحكم كأنواع محتوى مستقلة (فرع، نشاط، بطولة، إنجاز، خبر، ألبوم)، وليست نصوصاً ثابتة داخل الصفحة. هذا يرفع كلفة التطوير قليلاً لكنه يمنع مراجعتكم لنا عند كل تحديث.

النطاق الأول — الموقع الإلكتروني التعريفي

الإمكانيات المشمولة

  • ثمان صفحات: الرئيسية، من نحن، الأنشطة الرياضية، الفروع، الإنجازات والبطولات، الأخبار والفعاليات، الصور والفيديو، تواصل معنا
  • تصميم متجاوب بالكامل: جوال، لوحي، كمبيوتر
  • ثلاث لغات: العربية أساساً (RTL) مع الإنجليزية والإسبانية (LTR) وتبديل تلقائي لاتجاه الصفحة
  • لوحة تحكم عربية لإدارة الأخبار والفعاليات والأنشطة والفروع والإنجازات
  • معرض صور وفيديو مع دعم روابط YouTube وVimeo ورفع مباشر
  • صفحة فروع مع خرائط ومواعيد وبيانات تواصل لكل فرع
  • تقويم فعاليات قابل للفلترة حسب النشاط والفرع
  • نموذج تواصل مع حماية من الرسائل المزعجة وإشعار بريدي
  • زر واتساب عائم مع رسالة مُعدّة مسبقاً
  • SEO أساسي: عناوين ووصف لكل صفحة، خريطة موقع، ‎robots.txt‎، بيانات منظّمة Schema، روابط بديلة للغات
  • ربط Google Analytics 4 وSearch Console
  • شهادة SSL مع تجديد تلقائي
  • صلاحيات متعددة للمستخدمين: محرّر، ناشر، مدير
  • تحسين سرعة التحميل وضغط الصور تلقائياً

النطاق الثاني — المتجر الإلكتروني

الإمكانيات المشمولة

  • متجر مستقل بالكامل على خادم المدرسة، بدون اشتراك منصة
  • منتجات وتصنيفات غير محدودة العدد
  • خيارات المنتج: المقاسات والألوان والفئة العمرية مع مخزون منفصل لكل خيار
  • بحث وفلترة حسب التصنيف والسعر والمقاس والتوفر
  • سلة تُحفظ ويمكن إكمالها من جهاز آخر
  • صفحة دفع من خطوة واحدة، مع خيار الشراء كضيف
  • حساب العميل: الطلبات، عناوين الشحن، المفضلة، إعادة الطلب
  • لوحة إدارة الطلبات: الحالات، الطباعة، المرتجعات، الملاحظات الداخلية
  • إدارة المخزون مع تنبيه انخفاض الكمية
  • كوبونات خصم: نسبة أو مبلغ، حد أدنى للطلب، تاريخ صلاحية، عدد مرات الاستخدام، تخصيص لتصنيف
  • بوابة دفع سعودية: مدى، فيزا، ماستركارد، Apple Pay، والتقسيط عبر تابي وتمارا اختيارياً
  • ربط شركات الشحن: احتساب التكلفة، إنشاء البوليصة، رقم التتبع، تحديث حالة الشحنة
  • إشعارات بريد ورسائل نصية عند تغيّر حالة الطلب
  • تقارير المبيعات وأكثر المنتجات مبيعاً والسلات المتروكة
  • واجهة عربية وإنجليزية للمتجر (الإسبانية اختيارية بـ 2,000 ر.س)
  • بنية جاهزة للربط مع Odoo عبر API دون إعادة بناء

ربط Odoo — بند منفصل

كما طلبتم، الربط مُسعّر بشكل مستقل ويمكن تأجيله إلى ما بعد إطلاق المتجر. نبني طبقة مزامنة وسيطة تعمل عبر واجهات Odoo الرسمية، مع سجل عمليات وإعادة محاولة تلقائية عند فشل الاتصال، بحيث لا يتوقف المتجر عن البيع إذا توقف Odoo.

هذا القسم يستجيب مباشرةً لشرطكم، ونلتزم به تعاقدياً:

  1. الكود المصدري كاملاً ملك للمدرسة بعد سداد الدفعة الأخيرة، بلا أي قيد أو رخصة استخدام محدودة، ويحق لكم تعديله أو نقله لأي مطوّر آخر.
  2. التسليم عبر مستودع GitHub خاص مسجّل باسم المدرسة ومملوك لها منذ اليوم الأول من المشروع لا بعد التسليم — إضافةً إلى نسخة مضغوطة كاملة.
  3. قاعدة البيانات كاملة تُسلَّم كنسخة ‎dump‎ مع ملفات الوسائط ومفاتيح الإعدادات.
  4. حسابات الاستضافة والنطاق باسم المدرسة منذ الإنشاء، وبيانات الدخول لديكم، ولنا صلاحية فنية تسحبونها متى شئتم.
  5. لا اشتراك ولا ترخيص باسم المطوّر. جميع المكوّنات مفتوحة المصدر. وإن استدعت الحاجة أي أداة مدفوعة، تُشترى باسم المدرسة وبموافقتكم الخطية المسبقة وتُدرج في العرض قبل الشراء.
  6. توثيق فني يشمل بنية المشروع وخطوات النشر ومتغيّرات البيئة، مع فيديو تدريبي وجلسة تسليم مسجّلة.
  7. لا أي باب خلفي أو قفل تقني. ونلتزم بأن المشروع يعمل بالكامل بعد سحب صلاحياتنا.

ما نحتاجه منكم لبدء التنفيذ

  1. المحتوى النصي للصفحات بالعربية، وترجماته الإنجليزية والإسبانية أو تكليفنا بها.
  2. الهوية البصرية: الشعار بصيغة متجهة ‎SVG/AI‎، الألوان المعتمدة، الخطوط، وأي دليل هوية قائم.
  3. الصور والفيديوهات بجودة عالية لكل فرع ونشاط وبطولة.
  4. السجل التجاري أو الترخيص — لازم لتسجيل النطاق ‎.sa‎ ولاعتماد بوابة الدفع.
  5. فتح حساب تاجر لدى بوابة الدفع، والحساب البنكي باسم المدرسة.
  6. عقود أو حسابات شركات الشحن المطلوب ربطها.
  7. بيانات المنتجات: الاسم، الوصف، السعر، المقاسات، رقم ‎SKU‎، الصور.
  8. لربط Odoo: إصدار النظام، مكان استضافته، صلاحية ‎API‎، وقائمة الحقول المطلوب مزامنتها.
  9. تحديد مسؤول واحد من طرفكم لاعتماد المراحل، لتفادي تعارض الملاحظات وتأخير الجدول.
